Plugin author docs
------------------

We also ship a dedicated "plugin author" doc build (separate root) which reuses
the plugin pages above but scopes the API reference to plugin-facing modules.

Build it with `make html-plugin` (or on Windows: `.\make.bat html-plugin`).
